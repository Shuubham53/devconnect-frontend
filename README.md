# 🚀 DevConnect Frontend

A modern **developer community platform** inspired by LeetCode’s sleek dark UI. Built using **React + Vite**, focused on performance, real-time updates, and clean UX.

---

## 🌐 Live Demo

Deployed on **Vercel**

---

## 🛠️ Tech Stack

* ⚛️ React 18 + Vite
* 🔀 React Router v6 — client-side routing
* 🌐 Axios — API calls with JWT interceptor
* 🎨 Lucide React — modern icons
* 🔔 React Hot Toast — notifications
* ⚡ WebSocket — real-time updates

---

## ✨ Features

* 📰 **Feed System**

  * Latest / Following / Trending tabs

* 💬 **Post Detail**

  * Nested comments & reply threads

* 🔔 **Real-time Notifications**

  * Live notification badge using WebSocket

* 🏆 **Leaderboard**

  * Hero spotlight UI for top developers

* 👤 **User Profile**

  * Score history & activity tracking

* 🔍 **Explore Page**

  * Tag-based filtering system

* 🔎 **Search**

  * Search posts and developers

* 📌 **Bookmarks**

  * Save and manage posts

* 📱 **Responsive Design**

  * Mobile, tablet, desktop optimized

---

## 📄 Pages & Routes

| Route                | Page Description          |
| -------------------- | ------------------------- |
| `/feed`              | 📰 Main feed              |
| `/post/:id`          | 💬 Post detail + comments |
| `/profile/:username` | 👤 User profile           |
| `/explore`           | 🔍 Trending + tag filter  |
| `/leaderboard`       | 🏆 Top developers         |
| `/search`            | 🔎 Search posts & users   |
| `/bookmarks`         | 📌 Saved posts            |
| `/notifications`     | 🔔 Notification center    |
| `/create-post`       | ✍️ Create new post        |
| `/settings`          | ⚙️ Edit profile           |

## 🚀 Getting Started

```bash
# Clone the repo
git clone <your-repo-url>

# Navigate to project
cd devconnect-frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
